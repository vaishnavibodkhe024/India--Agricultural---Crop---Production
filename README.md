# 🌾 India's Agricultural Crop Production Analysis

## 📊 Data Analytics & Visualization Project

An interactive data analytics project that analyzes India's agricultural crop production using **Tableau**. The project explores production trends, crop-wise performance, state-wise production, cultivated area, yield, and regional patterns through interactive visualizations, a dashboard, and a Tableau story.

## 🎯 Project Overview

Agriculture is an important part of India's economy, and large agricultural datasets contain valuable information about crops, production, area, seasons, and regions.

However, raw agricultural data can be difficult to understand directly.

This project transforms the raw agricultural dataset into meaningful visual insights using **Tableau**.

The project focuses on:

- 📈 Production trends over the years
- 🌱 Crop-wise production analysis
- 🗺️ State-wise and geographical analysis
- 📊 Area and yield analysis
- 🌾 Crop distribution
- 🔎 Interactive filtering
- 📖 Story-based data presentation

---

## 🎯 Objectives

The main objectives of this project are:

1. To understand India's agricultural crop production data.
2. To inspect and clean the raw dataset.
3. To identify missing, duplicate, zero, and inconsistent data.
4. To prepare the dataset for visualization.
5. To create meaningful calculated fields such as Yield.
6. To analyze agricultural production across years and states.
7. To compare different crops and crop categories.
8. To create interactive Tableau visualizations.
9. To develop an interactive Tableau dashboard.
10. To create a Tableau Story for presenting important findings.
11. To integrate the Tableau visualizations into a Flask website.
12. To deploy the web application using GitHub and Vercel.

## 📁 Dataset

The dataset contains:

- **345,408 records**
- **10 columns**
- Data from **1997 to 2021**
- Production units including **Tonnes, Bales and Nuts**

The dataset contains information useful for analyzing:

- Crops
- States/Regions
- Seasons
- Production
- Area
- Year
- Crop categories
- Yield
